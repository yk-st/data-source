# MongoDB

MongoDB は、JSONに近いドキュメント形式でデータを保存するドキュメント指向データベースです。
スキーマを厳密に固定しなくてもデータを扱いやすく、アプリケーションの状態管理、ユーザーコンテキスト、イベントデータ、リアルタイムに近い参照用途などで広く利用されています。

リレーショナルデータベースのように表形式で厳密に管理するというよりも、アプリケーションで扱いやすいまとまりの単位でデータを保存しやすい点が特徴です。
そのため、分析基盤で加工した結果を業務アプリケーション向けに戻す保存先や、参照系のデータストアとしてもよく利用されます。

本リポジトリでは、主にリバースETLやリアルタイム系データの保存先としてMongoDBを利用します。

# 接続情報

## ワーキングコンテナからのアクセス

プログラム的に利用するエンドポイント
| 項目               | アクセス                                                                | ユーザー | パスワード |
|--------------------|-----------------------------------------------------------------------|----------|------------|
| 接続文字列       |  mongodb://action:pass123@docker.host.internal:27017/user_data  | action    | pass123          |
| Mongoshによる接続 |  mongosh -u action -p pass123 user_data | action   | pass123          |

※ユーザは今回ldapのデータを利用しています(ildffファイル参照)。
