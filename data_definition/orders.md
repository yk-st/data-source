### `id` (varchar)
- **定義**: 注文を一意に識別するためのプライマリキーです。
- **例**: `ORD001` は特定の注文ID。

### `user_id`（integer）
- **定義**: 注文を行ったユーザーのIDです。
- **例**: `3001` はユーザーのID。

### `product_id`（integer）
- **定義**: 注文された製品のIDです。
- **例**: `2001` は製品のID。

### `subtotal_usd`（numeric）
- **定義**: 税抜きの注文小計金額（米ドル）です。
- **例**: `100.50` は注文の小計金額。

### `tax_usd`（numeric）
- **定義**: 注文にかかる税金額（米ドル）です。売上税（Sales Tax）を指します。
- **例**: `10.05` は税金額。

### `total_usd`（numeric）
- **定義**: 注文の合計金額（米ドル）です（小計 + 税金）。
- **例**: `110.55` は注文の合計金額。

### `quantity`（integer）
- **定義**: 注文された商品の数量を示します。
- **例**: `2` は注文された商品の数。

### `flag`（integer）
- **定義**: 注文タイプフラグ。団体注文か個人注文かを区別します。
- **例**: `1` は個人注文、`2` は団体注文。

### `created_at`（timestamp）
- **定義**: 注文が行われた日時を示します。
- **例**: `2024-09-24 10:15:32` は注文の日時です。

### `parent_id`（bigint）
- **定義**: 親注文のID。分割注文や関連注文の場合に使用します。
- **例**: `1001` は親注文のID。通常の注文では `NULL`。

## 異常データの例

```
| order_id | 事象                 | 内容                                           |
| -------- | ------------------ | -------------------------------------------- |
| 1        | ユニーク違反 & タイムゾーン未変換 | 既存ID=1の重複入力、UTC（`2025-05-02 06:00:00Z`）のまま登録 |
| 101      | 通貨単位ミス             | 金額を円→セントと勘違いし`total_usd`を100倍（例:144.10→14410.0）  |
| 102      | SUBTOTAL 欠損        | 小計が手入力漏れで `subtotal_usd` が `NULL`                             |
| 103      | TAX に NaN          | 税額欄 `tax_usd` に「NaN」と入力                                 |
| 104      | 数量の桁違い（先頭0付与）      | `quantity` に `01` と先頭0付きで入力                  |

```
